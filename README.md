# popChoice — AI Movie Recommender

An AI-powered movie recommender that asks you a series of questions about your mood, genre preferences, and viewing habits, then suggests films tailored to your answers.

---

## Features

- Multi-page flow: question page → recommendation page
- AI-driven recommendations based on user responses
- Clean, minimal UI built with vanilla JavaScript

---

## Tech Stack

HTML · CSS · JavaScript · Vite

---

## Getting Started

```bash
npm install
npm run dev
```

Then open `http://localhost:5173` in your browser.

---

## Pages

| File | Description |
|------|-------------|
| `index.html` | Landing page |
| `questionPage.html` | Preference questionnaire |
| `moviePage.html` | Movie recommendations output |
